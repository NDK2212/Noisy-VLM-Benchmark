# Output-Level Metrics for Spatial Prompt Perturbations (OIP, CSR, APR, HAR)

This module computes the four output-level metrics proposed in the paper — **object identity
preservation (OIP)**, **contextual semantic drift (CSR)**, **attribute preservation recall (APR)**, and
**hallucinated attribute rate (HAR)** — for the spatial prompt perturbations (shift, upscale,
downscale) on **DAM-PACO**. It also reproduces the threshold calibration and the three figures of the
corresponding results.

| Paper item | Produced by | Output |
| :--- | :--- | :--- |
| Table of output-level metrics (definitions) | `metrics.py` | `outputs/metrics_spatial.csv` |
| Threshold calibration figure | `calibrate.py` + `plots.py` | `outputs/figures/fig5_calibration.{png,pdf}` |
| DAM under spatial perturbations (proposed metrics panel) | `metrics.py` + `plots.py` | `outputs/figures/fig11a_dam_spatial.{png,pdf}` |
| Cross-model comparison under shift and upscale | `metrics.py` + `plots.py` | `outputs/figures/fig12_cross_model.{png,pdf}` |
| Appendix: extraction prompt and synonym pairs | `extract.py`, `calibrate.py` | — |

All inputs, all GPT-4o-mini responses, and all outputs are included, so **every number and figure can
be reproduced without an OpenAI API key and without any API cost**.

## 1. Quick start

```bash
cd Benchmark_Evaluation/Output_Level_Metrics
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python extract.py      # reads cache/extractions.jsonl -> 0 API calls when the cache is present
python metrics.py      # OIP / CSR / APR / HAR per model, perturbation, and severity
python calibrate.py    # random-pair floor, matched pairs, synonym pairs
python plots.py        # the three figures (PNG + PDF)
```

The first run of `metrics.py` downloads `sentence-transformers/all-MiniLM-L6-v2` (~90 MB) from the
Hugging Face Hub. The whole pipeline runs on a CPU in a few minutes.

To re-run the extraction from scratch (e.g., with a different prompt or LLM), put your key in `.env`
(see `.env.example`), delete or move `cache/extractions.jsonl`, and run `python extract.py`.
A full run sends 21,504 unique captions to GPT-4o-mini and costs about US$1.5.

## 2. Pipeline

```
data/predictions/*.csv            31 files: 4 models x {clean, perturbed} x 1,500 regions
        │                         (model caption `pred_detailed` + GPT-4o reference `caption`)
        ▼
extract.py ── GPT-4o-mini ──────► cache/extractions.jsonl     raw JSON response per unique caption
        │                         outputs/extractions/*.csv   object + attributes per region
        ▼
metrics.py ── all-MiniLM-L6-v2 ─► outputs/metrics_per_region.csv   one row per region and condition
        │                         outputs/metrics_spatial.csv      mean over the 1,500 regions
        ▼
calibrate.py ───────────────────► outputs/calibration/            floor, matched pairs, synonyms
        ▼
plots.py ───────────────────────► outputs/figures/
```

| Step | Script | What it does |
| :--- | :--- | :--- |
| 1 | `extract.py` | Collects every unique caption (model outputs and GPT-4o references), sends each one once to GPT-4o-mini, appends the raw response to the cache, and writes one extraction CSV per input file plus `GT_reference_L0.csv` for the references. Captions already in the cache are not sent again. `--limit N` restricts the run to the first *N* regions of each file (pilot). |
| 2 | `metrics.py` | Embeds all objects and attributes, computes the four metrics for every region and condition, and averages them per model, perturbation, and severity. `--ref gt` (default) compares with the reference caption, as in the paper; `--ref clean` compares with the same model's caption under the clean box (written to `*_cleanref.csv`). |
| 3 | `calibrate.py` | Computes the random-pair floor, the reference–generated object pairs, and the synonym-pair similarities, and stores them for plotting. |
| 4 | `plots.py` | Draws the calibration figure, the DAM panel, and the cross-model figure. |

Shared helpers (file discovery and loading) are in `common.py`.

## 3. Metric definitions

For each region, GPT-4o-mini extracts the **primary object** `o` and the **attribute set** `A` from
the reference caption (subscript `r`) and from the caption generated by the model (subscript `p`).
Every phrase is embedded with `sentence-transformers/all-MiniLM-L6-v2` (L2-normalized), and `cos` is
the cosine similarity between embeddings.

| Metric | Definition | Better | What it captures |
| :--- | :--- | :---: | :--- |
| **OIP** | `1[cos(e(o_r), e(o_p)) >= 0.7]` | higher | The caption names the reference object (synonyms allowed). |
| **CSR** | `1 - cos(e(o_r), e(o_p))` | lower | How far, continuously, the named object drifts from the reference object. |
| **APR** | `|{a in A_r : max_{b in A_p} cos(e(a), e(b)) >= 0.6}| / |A_r|` | higher | Fraction of reference attributes that the caption recovers. |
| **HAR** | `|{b in A_p : max_{a in A_r} cos(e(a), e(b)) < 0.6}| / |A_p|` | lower | Fraction of stated attributes with no counterpart in the reference. |

**Reference.** The reference is the GPT-4o DAM-PACO caption of the region (column `caption`). It is a
fixed, model-independent anchor, so all models are scored against the same target. Each metric is also
computed under the clean (exact) box, and the effect of a perturbation is read as the change from that
clean value.

**Empty attribute sets.** If no attribute is extracted, the set is the empty string `""`, which is
embedded like any other phrase and matches no attribute. A caption without attributes therefore gets
`APR = 0` and `HAR = 1`. This affects 21–22% of the baseline captions and none of DAM's.

**Aggregation.** Metrics are computed per region and averaged over the 1,500 regions of each
(model, perturbation, severity) condition.

## 4. Object and attribute extraction

| Setting | Value |
| :--- | :--- |
| Model | `gpt-4o-mini` |
| Temperature | 0 |
| Output format | JSON mode (`response_format={"type": "json_object"}`) |
| User message | `Caption: {caption}` |
| Post-processing | lower-case, strip, remove duplicate attributes |
| Unique captions | 21,504 (20,004 model captions + 1,500 references) |

System prompt (`SYSTEM_PROMPT` in `extract.py`):

```text
You analyze a caption that describes one region of an image.
Extract:
1. "object": the primary object or object part the caption describes, as a short noun phrase
   (1-4 words, singular, no colors/materials/adjectives, e.g. "kettle lid", "trash can", "banner").
2. "attributes": the visual attributes stated for that object: color, material, shape, texture,
   finish, pattern, state/condition, size, and visible text or markings. Each attribute is a short
   phrase of 1-3 words (e.g. "red", "polished metal", "rounded", "glossy", "worn"). Do not include
   object names, positions, or the background. Do not repeat attributes. Use [] if none are stated.
Answer with JSON only: {"object": "...", "attributes": ["...", "..."]}
```

Example (from the cache):

```json
{"caption": "white design on black vase",
 "object": "vase", "attributes": ["white design", "black"]}
```

**Cache.** Every response is stored in `cache/extractions.jsonl` under the key
`sha1("gpt-4o-mini|v1|<caption>")`. Changing the model or `PROMPT_VERSION` in `extract.py` therefore
creates new keys and triggers a fresh extraction instead of silently reusing old responses.

## 5. Threshold calibration

The thresholds (0.7 for OIP, 0.6 for APR and HAR) are fixed in advance; `calibrate.py` checks that they
lie well above chance-level similarity.

| Quantity | How it is computed | Value |
| :--- | :--- | :--- |
| Random floor `b_floor` | mean cosine over 99,998 pairs of a randomly drawn object phrase and a randomly drawn attribute phrase (seed 0) | **0.1588** |
| Random pairs above 0.5 / 0.6 / 0.7 | share of the same pairs | 0.24% / 0.09% / 0.02% |
| Threshold / floor | 0.6 / b_floor and 0.7 / b_floor | 3.8x / 4.4x |
| Reference–generated object pairs | reference object vs. generated object, all 27 perturbed conditions x 1,500 regions | N = 40,500 (14.1% identical names, cos = 1) |
| Synonym pairs above 0.6 / 0.7 | 20 curated single-word pairs (list in `calibrate.py`) | 8 / 4 |

Pairing objects with objects and attributes with attributes instead gives a floor of 0.27; both values
are printed by `calibrate.py`.

## 6. Data and file formats

### `data/predictions/{Model}_{perturbation}_L{level}.csv`

Model captions on DAM-PACO, one row per region (1,500 rows, `ann_id` unique and identical across files).
`Model` ∈ {`DAM`, `GPT4Roi`, `Shikra`, `VipLlava`}; `perturbation` ∈ {`clean`, `shift`, `upscale`,
`downscale`}; `level` ∈ {0 (clean), 1, 3, 5}. Downscale was run for DAM only, so there are 10 DAM files
and 7 files per baseline.

| Column | Description |
| :--- | :--- |
| `ann_id`, `img_id` | PACO annotation and image IDs |
| `category` | PACO part/object category (e.g., `lid of kettle`) |
| `caption` | GPT-4o reference caption (DAM-PACO) |
| `bboxes` | box given to the model, `[x_min, y_min, x_max, y_max]`, after perturbation |
| `bbox_noise_type`, `bbox_severity` | perturbation type (`none` for clean) and severity |
| `pred_detailed` | caption generated by the model — **input to this module** |
| `summary_pred` | one-sentence summary of `pred_detailed` (used by the traditional-metric notebook, not here) |

DAM is evaluated in its box-prompt mode (box → SAM → mask → DAM). These files are column subsets of the
inference outputs of `Benchmark_Notebooks/`.

### `outputs/extractions/{Model}_{perturbation}_L{level}.csv` and `GT_reference_L0.csv`

| Column | Description |
| :--- | :--- |
| `ann_id`, `category` | as above |
| `pred_detailed` | the caption that was extracted (the reference caption in `GT_reference_L0.csv`) |
| `object` | extracted primary object |
| `attributes` | extracted attributes joined with `"; "`; empty string if none |

### `outputs/metrics_per_region.csv` and `outputs/metrics_spatial.csv`

`model, perturbation, level, [ann_id,] OIP, CSR, APR, HAR`. The per-region file has one row per region
and condition; the summary file has the mean per condition, including the clean box (`level = 0`).

### `outputs/calibration/`

`random.npy` (random-pair cosines), `matched_obj.npy` (reference–generated object cosines),
`matched_attr.npy` (best-match cosine of each reference attribute), `synonyms.csv`.

### Directory layout

```
Output_Level_Metrics/
├── README.md
├── requirements.txt
├── .env.example                 OPENAI_API_KEY (only needed to re-run the extraction)
├── common.py                    file discovery and loading

├── data/predictions/            31 input CSVs

└── outputs/
    ├── extractions/             32 CSVs (31 conditions + references)
    ├── metrics_per_region.csv
    ├── metrics_spatial.csv
    ├── calibration/
    └── figures/
```

## 7. Results

DAM (box → SAM → mask) on DAM-PACO, reference = GPT-4o caption, mean over 1,500 regions:

| Perturbation | Level | OIP ↑ | CSR ↓ | APR ↑ | HAR ↓ |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Clean box | 0 | 0.433 | 0.380 | 0.291 | 0.590 |
| Shift | 1 / 3 / 5 | 0.426 / 0.367 / 0.279 | 0.386 / 0.428 / 0.503 | 0.287 / 0.264 / 0.231 | 0.594 / 0.633 / 0.675 |
| Downscale | 1 / 3 / 5 | 0.426 / 0.387 / 0.339 | 0.384 / 0.413 / 0.453 | 0.285 / 0.270 / 0.257 | 0.596 / 0.613 / 0.634 |
| Upscale | 1 / 3 / 5 | 0.440 / 0.431 / 0.424 | 0.375 / 0.380 / 0.391 | 0.293 / 0.287 / 0.280 | 0.590 / 0.600 / 0.615 |

Baselines under the clean box: OIP 0.32–0.39, APR 0.04–0.06, HAR 0.72–0.74. Pairing each caption with
the reference of a randomly chosen other region gives OIP ≤ 0.013 and HAR 0.83–0.89 (chance level).
All conditions are in `outputs/metrics_spatial.csv`.

## 8. Reproducibility notes

- **Exact reproduction.** With the shipped cache, `extract.py` makes no API calls and every output file
  in `outputs/` is reproduced byte for byte.
- **Re-extraction.** GPT-4o-mini at temperature 0 is not guaranteed to be deterministic, so a fresh
  extraction can change individual phrases and move the averages slightly.
- **Randomness.** The random pairs in `calibrate.py` use `random.Random(0)`; KDE sampling in `plots.py`
  uses `numpy.random.default_rng(0)`.
- **Tested with** Python 3.14, numpy 2.5, pandas 3.0, scipy 1.18, matplotlib 3.11, openai 3.26,
  sentence-transformers 6.1, torch 2.14.

## 9. Known limitations

- **Synonyms versus opposite values.** `all-MiniLM-L6-v2` separates related from unrelated phrases (see
  the floor), but it does not reliably separate opposite values of the same property: for example,
  *glossy finish*–*matte finish* scores 0.74 and *red color*–*blue color* 0.72, above the 0.6 attribute
  threshold. APR and HAR therefore measure whether a caption describes the same *properties* as the
  reference more than whether it assigns them the same *values*. Value-level errors are captured by the
  judge-based scores on DLC-Bench and by CLAIR.
- **Reference coverage.** The GPT-4o references do not list every visible attribute, so correct details
  that a reference omits count as unmatched; this keeps the absolute HAR high even under the clean box.
- **Extraction model.** The metrics depend on an LLM extraction step and have not been validated against
  human judgments; we interpret them through their change from the clean box rather than their absolute
  values.
